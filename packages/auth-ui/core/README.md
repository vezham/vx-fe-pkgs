# @vezham/auth-ui-core

Local Vezham authentication configuration, validation, queries, mutations, plugin contracts, billing/activity adapters, and server helpers.

The implementation is maintained in this package. It uses the Better Auth engine through `@vezham/auth`; no `@better-auth-ui/*` packages are installed. See [third-party notices](./THIRD_PARTY_NOTICES.md) for the MIT source attribution.

Run `pnpm nx run auth-ui-core:test` and `pnpm nx run auth-ui-core:build` from the workspace root.
