## Usage

```tsx
import { CardGallery } from '@vezham/react/layouts/card-gallery'
```

Place cards inside `CardGallery.Group`. Feature groups contain one large card; tile groups stack smaller cards. The scrollable region is keyboard-focusable and has an accessible label.

## Anatomy

```tsx
<CardGallery aria-label="Explore resources">
  <CardGallery.Group aria-label="Featured">
    <CardGallery.Card title="Components" />
  </CardGallery.Group>
  <CardGallery.Group variant="tiles" aria-label="Guides">
    <CardGallery.Card variant="tile" title="Getting started" />
    <CardGallery.Card variant="tile" title="Recipes" />
  </CardGallery.Group>
</CardGallery>
```

Match `Group variant="tiles"` with `Card variant="tile"`. Group labels describe each column. The card layout uses the same visual and action slots as Bento.

## API Reference

### CardGallery

Accepts native nav props and these labels:

| Prop          | Type     | Default              | Description                           |
| ------------- | -------- | -------------------- | ------------------------------------- |
| `aria-label`  | `string` | `'Card gallery'`     | Gallery navigation label.             |
| `scrollLabel` | `string` | `'Scrollable cards'` | Accessible name of the scroll region. |

### CardGallery.Group

Accepts native list-item props. `variant` is `'feature'` by default, or `'tiles'` for a stacked column. Supply `aria-label` to identify the group.

### CardGallery.Card

`variant` is `'feature'` by default, or `'tile'` for a compact card. Feature cards are 450px tall and tiles are 215px tall, increasing to 500px and 240px at 737px. The gallery provides horizontal scrolling when its columns exceed the available width.

The card accepts these content slots:

| Prop          | Type                                   | Default  | Description                                        |
| ------------- | -------------------------------------- | -------- | -------------------------------------------------- |
| `title`       | `ReactNode`                            | Required | Main card heading.                                 |
| `eyebrow`     | `ReactNode`                            | —        | Small label above the heading.                     |
| `description` | `ReactNode`                            | —        | Supporting text.                                   |
| `icon`        | `ReactNode`                            | —        | Decorative icon beside the label.                  |
| `children`    | `ReactNode`                            | —        | Visual content below the header.                   |
| `action`      | `ReactNode`                            | —        | Action node, typically the matching `Action` part. |
| `headingAs`   | `'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6'` | `'h2'`   | Heading level for the page hierarchy.              |
| `className`   | `string`                               | —        | Appearance, spacing, and grid-span overrides.      |

Card parts also accept native div props. The shared React stylesheet includes hover and focus feedback; scale feedback respects reduced-motion preferences.

### CardGallery.Action

The `Action` part creates a link covering the card with an arrow in its lower corner. Its `href` and `aria-label` are required. Native link props such as `target`, `rel`, and `download` pass through. Supply `children` to replace the decorative arrow.

Use decorative visual content inside a card with an overlay action. Keep locale resolution in the consuming app and pass the resolved URL to `href`.

Use `CardGallery.Action` for the overlay action. The entry point exports `CardGalleryProps`, `CardGalleryGroupProps`, `CardGalleryCardProps`, and `CardGalleryActionProps`.
