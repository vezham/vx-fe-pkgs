## Usage

Render inside [Auth.Provider](/docs/ui/auth/web/components/auth-provider). The preview uses an isolated local account and transport.

```tsx
import { Auth } from '@vezham/react/auth'

export const Example = () => <Auth.ResetLinkSent />
```

The forgot-password flow stores the submitted email and opens this confirmation view. Its email-provider button appears when a known provider is available.
