## Usage

Render inside [Auth.Provider](/docs/ui/auth/web/components/auth-provider). The preview uses an isolated local account and transport.

```tsx
import { Auth } from '@vezham/react/auth'

export const Example = () => <Auth.Redirect />
```

`Auth.Redirect` checks the current session and invokes the provider navigation callback. Use it on an application route where navigation is expected.

import type { AuthRedirectProps } from '@vezham/react/auth'
