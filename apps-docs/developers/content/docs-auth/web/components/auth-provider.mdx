## Usage

Create one auth client and wrap your application in `Auth.Provider`. Supply your application router through `navigate`.

```tsx title="auth-client.ts"
import { createAuthClient } from '@vezham/auth/react'

export const authClient = createAuthClient()
```

```tsx title="auth-provider.tsx"
import type { ReactNode } from 'react'

import { Auth } from '@vezham/react/auth'

import { authClient } from './auth-client'

export const AuthProvider = ({ children }: { children: ReactNode }) => (
  <Auth.Provider
    authClient={authClient}
    navigate={({ to }) => window.location.assign(to)}>
    {children}
  </Auth.Provider>
)
```

For client navigation, use the [TanStack Start](/docs/ui/auth/web/integrations/tanstack-start) or [Next.js](/docs/ui/auth/web/integrations/nextjs) adapter. Pass `queryClient` to reuse an existing TanStack Query cache.

## Localization

Override product-specific messages with `localization`, or pass an application-owned locale through `locale`.

```tsx
<Auth.Provider
  authClient={authClient}
  navigate={navigate}
  localization={{ auth: { signIn: 'Welcome back' } }}>
  {children}
</Auth.Provider>
```

## Plugins

Register each UI plugin in `plugins` after enabling its matching server and client plugin. See the [plugin guides](/docs/ui/auth/web/plugins/two-factor).

## Props

```tsx
import type { AuthProviderProps } from '@vezham/react/auth'
```

Use the exported props type for inherited configuration and component props.
