title: Passwords
description: Configure password forms and their validation rules.
---

Configure the client form rules to match your auth server. The default minimum is 8 characters and the maximum is 128. The password-strength meter is a browser hint and does not decide whether submission is allowed.

```tsx title="password-options.tsx"
import { Auth } from '@vezham/react/auth'

export const SignUp = () => (
  <Auth.Provider
    authClient={authClient}
    navigate={navigate}
    emailAndPassword={{
      enabled: true,
      minPasswordLength: 12,
      maxPasswordLength: 128,
      confirmPassword: true,
      forgotPassword: true,
      rememberMe: true,
      strengthMeter: true
    }}>
    <Auth.SignUp />
  </Auth.Provider>
)
```

Here `authClient` and `navigate` come from [Quick Start](/docs/ui/auth/web/getting-started). Configure the same password length policy on your auth server.

## Recovery and changes

[`Auth.ForgotPassword`](/docs/ui/auth/web/components/auth/forgot-password) submits a recovery email. Configure the backend callback to send [`AuthEmail.ResetPassword`](/docs/ui/auth/web/components/email/reset-password-email) with its generated URL. The URL must open the reset route with a `token` query parameter.

[`Auth.ResetPassword`](/docs/ui/auth/web/components/auth/reset-password) consumes that token. Signed-in users can use [`Auth.Settings.Security.ChangePassword`](/docs/ui/auth/web/components/settings/security/change-password), which asks for the current password when the account has a credential login.

Set `requireEmailVerification` when the server requires verified email. Use the [Email OTP](/docs/ui/auth/web/plugins/email-otp) plugin for code-based recovery, or [Passkey](/docs/ui/auth/web/plugins/passkey) for a passkey sign-in option.
